# 模型与视觉样式

社区版首页使用独立制作的虚构公寓。暖木、米白、橄榄绿配色参考“居所”的视觉风格；房间布局、家具与纹理均来自社区版自己的生成代码，不包含作者的真实户型。

## 普通使用不需要 Blender

候选包已附带 `public/assets/community-detail-v6.glb`，模型与光影纹理打包在一个文件中。光影先烘焙到线性浮点图像，再经 AgX 压缩高光后保存为 PNG；网页材质不重复进行色调映射，以保留浅色布艺的明暗层次。按入门教程运行即可；不会下载外部图片、调用 AI 或读取家庭照片。

模型逐步加载：页面先显示轻量基础模型，精细模型准备好后显示软包家具、木纹、布艺与暖光。加载失败时基础模型和设备页面仍能使用。旋转、缩放、双击复位与空间热点沿用同一套交互。

模拟灯开关会调节对应虚构区域的明暗：开灯保持受限的暖光亮度，关灯保留低亮度环境光，其他房间保持自己的状态。离线、未知或未绑定的灯显示中性明暗，不当作确认关闭。精细模型的光影已预先计算，切换灯光不会重新计算整屋反射与阴影。用户接入自己的 HA 后，模型仍是演示户型，不会自动变成真实住宅，也不会自动推断设备位置。

## 想二次开发

- `public/scene.mjs`：相机、手势、基础模型、设备热点与加载衔接。
- `public/scene-look.mjs`：基础模型的程序材质与实时灯光。
- `public/detailed-model.mjs`：精细模型加载与示例灯明暗绑定。
- `scripts/create-community-model.py`：社区版独立 Blender 生成器，包含虚构几何、程序材质与光影设置。

修改布局属于模型制作，需要同时调整热点位置和示例灯的区域。仅修改原有物体的材质参数不会暴露或引入真实户型；请不要把你自己的家庭测量数据、设备标识或原始私密模型直接提交到公共仓库。

## 重新制作模型（进阶，可跳过）

需要本机 Blender 4.5 或更新版本，以下命令假设 `blender` 已加入命令行路径；普通安装和使用社区版不需要这些步骤。

1. 在项目目录运行，选择一个全新的输出目录以保留旧成果：

   ```sh
   blender --background --python scripts/create-community-model.py -- --output .local/my-model-v1
   ```

2. 先看输出目录中的 `overview.png`，确认户型和材质符合预期。`community-source.blend` 是可编辑工作文件。
3. 再生成网页用的光影与模型：

   ```sh
   blender --background --python scripts/create-community-model.py -- --output .local/my-model-v1 --bake
   ```

4. `community-lighting.exr` 是本地保留的高动态范围烘焙源，不需要上传。输出的 `community-detail.glb` 是网页候选资源；先在本地审阅，再用新文件名放入 `public/assets/` 并更新加载地址、测试与发布白名单。不要把整个 `.local` 文件夹上传。
5. 运行 `npm test` 和 `npm run check`，再打开网页检查实际效果、旋转和设备热点。原始 Blender 渲染通过不代表网页已通过验收。

生成器不覆盖已有工作工程或已导出的 GLB。需要调整时使用新的输出目录；旧目录由作者自行决定是否保留。
