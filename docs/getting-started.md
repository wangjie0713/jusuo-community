# 第一次运行

## 先准备

拿到的是 **jusuo-community** 文件夹，只在这个文件夹里操作。不要进入你原来的智能家居目录。

如果电脑还没有 Node.js，从 [Node.js 官方下载页](https://nodejs.org/en/download) 选择 24.x 安装包并安装；安装后重新打开终端。已有 Node 24 就跳过。

## Mac

1. Finder 打开社区版文件夹。
2. 打开“终端”，输入 `cd `（注意后面有一个空格），把该文件夹拖到终端，再按回车。这会自动填写正确路径。
3. 输入 `node --version`。看到 `v24.` 开头就继续。
4. 输入 `npm start`。
5. 浏览器打开 `http://127.0.0.1:4177`。

## Windows

1. 资源管理器打开社区版文件夹，在地址栏输入 `powershell` 后回车。
2. 输入 `node --version`，应显示 `v24.` 开头。
3. 输入 `npm.cmd start`。使用 `.cmd` 可避开部分 Windows 对 PowerShell 脚本的执行限制，不需要降低系统安全策略。
4. 浏览器打开 `http://127.0.0.1:4177`。

成功标志：首页时钟区显示“模拟预览”，全部设备页显示 6 个虚构设备，其中玄关灯为离线示例。点击左上角菜单进入设备页；开关灯只改变模拟状态，在空调详情中调温可立即看到模拟结果。

静置约 6 秒后，房子会缓慢自动旋转，约 5 分钟一圈。鼠标拖动/滚轮或触屏双指缩放可浏览模型，双击复位；10 秒不操作也会复位。默认视角触屏左滑进入设备页，右滑回首页。系统开启“减少动态效果”时不自动旋转。

## 如何停止、重新打开

在运行服务的终端按 `Ctrl+C` 停止。下次回到同一文件夹运行启动命令。模拟数据每次重启会还原。

## 排障

| 看到什么 | 下一步 |
| --- | --- |
| `node` 不是命令 / command not found | 安装 Node 24，关闭并重新打开终端，再查版本 |
| 找不到 package.json | 当前不在项目目录；回到含 README.md、package.json 的文件夹 |
| 提示 deploy/.env 不存在，随后显示地址 | 正常；模拟家庭不需要这个文件 |
| 端口被占用 | 不要停止其他项目；Mac 用 `CE_PORT=4178 npm start`；PowerShell 先 `$env:CE_PORT='4178'` 再 `npm.cmd start`，浏览器改为 4178 |
| 页面打不开 | 保持启动终端打开，使用它显示的完整 HTTP 地址；检查是否有启动错误 |
| 3D 无法显示 | 使用支持 WebGL 的 Chrome / Safari，启用硬件加速；下方设备仍可用 |
| 操作结果待核实 | 不连续重发；先点右上角刷新确认状态，真实模式还应在 HA 中查看 |
| 设备离线 | 演示玄关灯故意离线；真实模式先在 HA 恢复设备连接 |
| 页面显示旧内容 | 浏览器刷新；本版不注册 Service Worker，不缓存设备 API |

不能从手机直接访问电脑的 `127.0.0.1`：它始终表示正在使用的那台设备。手机 / iPad 真机接入需要单独设置 HTTPS、认证和局域网入口，参照配置教程；本次本地预览没有打开局域网访问。
