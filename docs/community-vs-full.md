# 社区版与完整方案

| 目标 | 社区版 | 私人完整方案 / 后续服务方向 |
| --- | --- | --- |
| 看效果 | 虚构空间、模拟设备、基础响应式 UI | 真实家庭空间与日常场景 |
| 控制设备 | 明确支持的灯与空调、回读确认 | 多品牌、多设备能力适配和现场验证 |
| AI | 不包含完整 AI 模块、提示词、记忆或语音链路 | 可能作为专业能力，范围待定义 |
| 户型 | 几何生成的虚构模型源码 | 定制测绘 / 建模 / 设备定位服务 |
| 自动化 | 本次无个人家庭策略 | 家庭场景设计、联动排障与长期维护 |
| 部署 | 本机模拟教程、基础接入说明 | 付费安装、证书网络配置、跨平台调试、培训 |
| 隐私数据 | 只有虚构示例 | 所有真实配置仅在各自环境中维护 |

未来适合收费的是部署结果、适配效率、复杂场景设计和持续支持。保留未公开的独立专业模块，也能为产品化留空间。不要依赖“代码别人看不懂”形成门槛。

暂不开源：完整 AI 实现及策略、真实户型及对应素材、家庭自动化规则、真实设备映射、账号/密钥、摄像头/NAS、车辆轨迹、家庭成员、安装日志和商业方案。授权不清楚的图片、音频、字体也不进入包。

公共版的错误提示、参数校验、认证和基本安全不会作为付费门槛。公开前要让社区版自身形成完整的基础体验，不靠付费才能启动演示。

当前没有发布专业版产品、价格或交付日期。所有服务方向只是保留选项。
